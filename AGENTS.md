# spec

SoT: `notes/idea.md` = live USER spec (wants · features · ideas · decisions).

## write — same turn, before code

Merge on any USER:

- feature / spec / desire / idea
- plan change / refine / drop / reject / postpone
- decision (incl. answers to agent Qs)
- accepted agent proposal

Do this even if USER only said “implement” / never said “update idea.md”.

## how

- rewrite **current desired state** in place
- headings by topic (product · features · UX · constraints · non-goals · …) — grow as needed
- latest USER statement wins
- superseded text → **delete** (not strike, not “was X now Y”)
- dropped feature → **delete the section**
- new want → add under topic
- only USER-originated + USER-accepted
- USER silence ≠ accept
- ❌ changelog · dates · history · impl USER did not decide · agent guesses

## read

Before plan / implement / review vs wants → read `notes/idea.md`.
